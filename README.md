# 💰 SkyPro Wallet

Современное веб-приложение для управления личными финансами с возможностью отслеживания расходов, их категоризации и детального анализа через интерактивные графики и календарь.

## 📖 Описание проекта

**SkyPro Wallet** - это полнофункциональное приложение для управления личным бюджетом, разработанное на React 19. Приложение предоставляет интуитивно понятный интерфейс для:

- Добавления и редактирования расходов
- Категоризации трат (еда, транспорт, жилье, развлечения, образование)
- Фильтрации и сортировки транзакций
- Визуального анализа расходов за выбранный период
- Безопасной аутентификации пользователей

## 📦 Установка и запуск проекта

### Предварительные требования

- Node.js версии 18.x или выше
- npm или yarn

### Шаги установки

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/your-username/skypro-wallet.git
   cd skypro-wallet
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки:**

   ```bash
   npm run dev
   ```

4. **Откройте приложение в браузере:**
   ```
   http://localhost:5173
   ```

### Доступные команды

| Команда           | Описание                                   |

## 🎨 Архитектурные решения

### Принципы разработки

Проект построен с соблюдением принципов **KISS**, **DRY** и **YAGNI**:

- ✅ **KISS** (Keep It Simple, Stupid) - простота и понятность кода
- ✅ **DRY** (Don't Repeat Yourself) - переиспользование компонентов и стилей
- ✅ **YAGNI** (You Aren't Gonna Need It) - только необходимый функционал

### Styled Components

- Использование CSS-in-JS для изоляции стилей
- Создание переиспользуемых миксинов и констант
- Единый `mobileQuery` для всех media queries
- Условная стилизация через props (`$error`, `$filled`, `$active`)

### State Management

- React Context API для глобального состояния аутентификации
- Local state для компонентных данных
- Custom hooks для переиспользуемой логики

### API интеграция

- Централизованные API модули
- Автоматические retry при ошибках сети
- Обработка ошибок с пользовательскими сообщениями
- Bearer token аутентификация

## 🛠️ Особенности реализации

### Форматирование данных

- **Сумма**: автоматическое разделение тысяч пробелами (например: `2 500`)
- **Дата**: маска ввода в формате `ДД.ММ.ГГГГ` с автоматическим добавлением точек
- **Категории**: 6 предустановленных категорий с иконками

### Обработка ошибок

- Retry механизм для сетевых запросов (до 3 попыток)
- Обработка ошибок 5xx статусов
- Пользовательские сообщения об ошибках
- Валидация на клиентской стороне перед отправкой

### Производительность

- Мемоизация компонентов при необходимости
- Оптимизация ре-рендеров
- Lazy loading для маршрутов
- Debounce для частых операций

## 📝 API Endpoints

### Аутентификация

- `POST /api/user/login` - Вход в систему
- `POST /api/user` - Регистрация нового пользователя

### Транзакции

- `GET /api/transactions` - Получение списка транзакций
- `GET /api/transactions?sortBy=date|sum&filterBy=food,transport` - С фильтрами
- `POST /api/transactions` - Создание новой транзакции
- `PUT /api/transactions/:id` - Обновление транзакции
- `DELETE /api/transactions/:id` - Удаление транзакции
- `POST /api/transactions/period` - Получение транзакций за период
